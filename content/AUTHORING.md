# 作問ガイド

教材は1単元につき「概念 6〜8件・誤答パターン 6〜8件・問題15問」を基本とする。既存単元（例: `problems/math1/quadratic-function/`）を書式見本にすること。

## ファイル配置

| 種類 | 置き場所 | ID |
|---|---|---|
| 単元の登録 | `curriculum.yaml` | `<科目ID小文字>-<単元名>`（例: `math2-exp-log`） |
| 概念 | `concepts/<科目ID>/<単元名>/NN-<slug>.yaml` | `<単元コード>-<slug>` |
| 誤答パターン | `misconceptions/<単元ID>.yaml` | `mc-<単元コード>-<slug>` |
| 問題 | `problems/<科目ID>/<単元名>/{s,a,e}NN-<slug>.yaml` | `<科目略号>-<単元コード>-s01` など |

概念の `prerequisites` と誤答パターンの `remedyConcepts` は、他単元を含め既存のIDだけを参照する。

## 問題の構成

- レベル: `school`（教科書例題〜章末）、`applied`（共通テスト、誘導付き）、`exam`（国公立二次・難関私大）を各5問。
- 各レベルの形式: 選択式2問、マーク式2問、記述式1問。

### 選択式 (`choice`)
- 選択肢は ①〜④ の4つ（id `"1"`〜`"4"`）。問題文の末尾は「次の①〜④のうちから一つ選べ。」。正解の位置は問題ごとに散らす。
- 誤答の選択肢は、それぞれ特定の誤答パターンを体現させ、合うものには `misconception:` を付ける。`rationale` には、どういう誤りでその選択肢に至るかを書く。正解の `rationale` は「正解。」で始める。

### マーク式 (`mark`)
- 問題文に共通テスト形式の空欄 `\boxed{\text{ア}}` を置く。分数・根号は既約・最簡形で空欄を分ける。
- 各ラベルの `answer` は数字と符号だけの文字列にし、ラベルの文字数を桁数に合わせる。`accept` は正当な別表記に限る。

### 記述式 (`written`)
- `modelAnswer` は、上位の受験生が書く完全な答案にする。
- `rubric` は4〜5項目で合計10点。各基準は具体的で採点可能にする。
- `keywords` には、入力された答案に文字どおり現れそうな短い文字列を入れる（オフライン時の簡易採点に使う）。

### 共通項目
- `solution`: 要点を簡潔に書いた解説。
- `author.intent`: 出題者の視点から、その問題が何を見分けるよう設計されているか。
- `assessedAbilities`: [知識・技能, 思考力・判断力・表現力] から選ぶ。
- `curriculumRefs`: 平成30年告示学習指導要領の項目。
- `variations`: 類題のアイデアを1〜2件。
- `irt.expectedCorrectRate`: 全国の想定正答率（目安: 学校数学 0.6〜0.85、応用 0.4〜0.6、入試 0.15〜0.4）。
- `discrimination`: 0.8〜1.5。
- `targetSeconds`: 現実的な目安時間（秒）。

## 書式
- 数式は KaTeX（`$...$`、`$$...$$`）で書く。不等号は `\leqq` `\geqq` を使う。数式内の日本語は `\text{}` で囲む。
- 図は表示できないので、頂点名・位置関係・長さや角を文章で完全に記述する。データは Markdown の表で示す。
- YAML のダブルクォート文字列にはバックスラッシュを入れない（`|` ブロックか単一引用符を使う）。

## 検算と検証
- **正しさが最優先。** 全問について、意図した解法とは独立に答えを計算するスクリプト（sympy・総当たり・座標による図形の構成）で正解を確かめ、各誤答の選択肢が実際に誤りであることも確認する。
- `npm run content:check` は、出力を書き換えずに検証だけを行う（KaTeX の strict 検査と、参照の整合性の確認を含む）。
